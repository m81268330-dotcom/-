# Yas build OS

وب‌اپ فارسی و راست‌به‌چپ، ساخته‌شده بر اساس تصویر مرجع؛ بدون نیاز به نصب وابستگی یا ساخت پروژه.

## اجرا

فایل `index.html` را باز کنید یا از دستور `node server.cjs` استفاده کنید و به `http://localhost:4173` بروید.

امکانات: داشبورد، ایجاد و جست‌وجوی پروژه، تغییر وضعیت و پیشرفت، معرفی سیستم‌های سازه‌ای، محاسبه اولیه سقف و پله، چاپ، خروجی CSV و JSON، ذخیره محلی، نمای واکنش‌گرا.

این نسخه احراز هویت یا سرور داده ندارد. داده‌ها در localStorage مرورگر ذخیره می‌شوند. محاسبات صرفاً برآورد اولیه هستند و برای طراحی اجرایی باید توسط مهندس دارای صلاحیت بررسی شوند.

## GitHub Pages

فایل‌های ریشه را در شاخه `main` قرار دهید. در Settings → Pages، گزینه Deploy from a branch را روی `main` و `/ (root)` تنظیم کنید. فایل `.nojekyll` امکان انتشار مستقیم فایل‌های استاتیک را فراهم می‌کند.

فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ در نبود اینترنت فونت Tahoma جایگزین است.
